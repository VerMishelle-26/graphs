\# Графы: DirectedGraph, BFS, матрица и список смежности



Учебный проект по алгоритмам и структурам данных.



\## Что реализовано



1\. \*\*К1\*\* — класс `DirectedGraph` с `add\_vertex` и `add\_edge`.

2\. \*\*К2\*\* — обход в ширину `bfs(graph, start)`.

3\. \*\*К3\*\* — матрица смежности из списка рёбер (`create\_adjacency\_matrix`, `add\_vertex\_matrix`, `add\_edge\_matrix`).

4\. \*\*К4\*\* — список смежности из списка рёбер (`create\_adjacency\_list`, `add\_vertex\_list`, `add\_edge\_list`).



\## Анализ



\### DirectedGraph

\- Хранение в словаре: `{вершина: \[соседи]}`.

\- `add\_vertex` и `add\_edge` — O(1).



\### BFS

\- \*\*Сложность:\*\* O(V + E), где V — вершины, E — рёбра.

\- \*\*Память:\*\* O(V) — очередь.



\### Матрица смежности

\- \*\*Память:\*\* O(V²).

\- \*\*Проверка ребра:\*\* O(1).

\- \*\*Подходит для плотных графов.\*\*



\### Список смежности

\- \*\*Память:\*\* O(V + E).

\- \*\*Перебор соседей:\*\* O(степень вершины).

\- \*\*Подходит для разреженных графов.\*\*
